    Most of the surcharge is not the language

    Every language except English pays more to say the same thing to a language model. Above is one sentence, in … of them, with identical meaning: each tile is one token — the chunks a tokenizer cuts text into, the unit you are billed in, and the unit a context window is measured in. In English a token is usually a whole word. Elsewhere it is a fragment of one, sometimes a fragment of a single character. The dashed line is what English costs. Everything past it is the surcharge, and this study is about how much of that is a choice.
